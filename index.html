安装

推荐终端一行命令：下载、安装、配置、开机自启一次完成，且不触发浏览器下载的 Gatekeeper 拦截。

JavaScript 未启用；请用下面的手动安装。

脚本会询问两样东西：网关地址和个人 token。不知道就先问网关管理员要，token 输入时不回显、只落在本机 ~/.config/aladdin/config.json（0600）。

手动安装

  1. 解压 Aladdin.app.zip，把 Aladdin.app 拖进「应用程序」。浏览器下载的包首次打开会被 Gatekeeper 拦下（应用未经 Apple 公证）：右键 → 打开，或先执行 
    xattr -dr com.apple.quarantine ~/Applications/Aladdin.app
  2. 按提示授予系统权限：麦克风、辅助功能、输入监控；再把 系统设置 → 键盘 → 「按下 🌐 键时」改为「无操作」，并关闭系统听写，避免两次 Fn 与系统抢按键。
  3. 菜单栏 Aladdin 图标 → 打开配置，填入网关地址与个人 token，重新启动应用。
Aladdin 是团队内部工具：转写与对话都经由团队自己的网关，本机不存任何 API key。没有网关 token 的话，应用能启动但不能工作。
